## Nginx proxy user management

```
- Add/remove users
- Reset the password
- Permission
  > item visibility [Created Item Only | All Items]
  > proxy Hosts: [Manage | View Only | Hidden]
  > Redirection Hosts: [Manage | View Only | Hidden]
  > 404 Hosts: [Manage | View Only | Hidden]
  > Streams: [Manage | View Only | Hidden]
  > Access lists: [Manage | View Only | Hidden]
  > SSL Certificates: [Manage | View Only | Hidden]

```

**Valiodation:**

```
- Login the user
- See the WEbUI for proxymanager
- You may not see/get all the options
```
