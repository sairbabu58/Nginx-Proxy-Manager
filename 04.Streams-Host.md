## Add and configure Stream Host

Note:

- Connect your vm over ssh using proxy host
  
- Connect/access non http/https port


```
- jump Host 192.168.0.30| jump-host.j2ctechnologies.com
- other host  192.168.0.31

```

```
- add additional port inside of your proxy manager compose file

    ports:
      # These ports are in format <host-port>:<container-port>
      - '80:80' # Public HTTP Port
      - '443:443' # Public HTTPS Port
      - '81:81' # Admin Web Port
      # Add any other Stream port you want to expose
      # - '21:21' # FTP
      - '2022:2022' # SSH
      - '3036:3036' #MySql 
      - '8082:8082' #Custom
```

```
- Proxy Manager Web-UI
- Hosts > New Stream
    Incoming Port: 8082
    Forward Host: 192.168.0.30
    Forward Port: 22
```

**Test the Access**
```
- ssh <proxyhost-IP> -p 8082
- ip a
- It should connect to 192.168.0.30
```


```
- Proxy Manager Web-UI
- Hosts > New Stream
    Incoming Port: 2022
    Forward Host: 192.168.0.31
    Forward Port: 22

```

**Test the Access**
```
- ssh <proxyhost-IP> -p 2022
- ip a
- It should connect to 192.168.0.31
```
